📖 Panduan Order Manager PRO+

Cara menggunakan fitur utama.

Ruang iklan

1. Tambah order

Masukkan satu order per baris lalu tekan Tambah Order. Jika teks yang sama sudah ada, order baru tidak akan dimasukkan.

2. Tulis deadline

Contoh: hari ini 15:30, besok jam 09.00, lusa, Senin 10:00, Senin depan, 28 Agustus, 28 Agustus 2026, 28/08/2026, 28-08-2026, 2026-08-28, atau tanggal 25.

3. Status

Gunakan tiga tab untuk memisahkan order Belum, Sedang Diproses, dan Selesai.

4. Prioritas

Deadline yang lewat atau paling dekat otomatis berada di bagian atas. Order tanpa tanggal berada setelah order terjadwal. Status Selesai dipisahkan pada tabnya sendiri.

5. Drag & drop

Geser kartu untuk mengatur prioritas manual. Tombol ▲ dan ▼ juga tersedia.

6. Undo Delete

Setelah menghapus order, tekan Undo dalam beberapa detik untuk mengembalikannya.

❓ FAQ

Pertanyaan yang sering ditanyakan.

Apakah data saya tersimpan?

Ya. Versi ini menggunakan penyimpanan browser (localStorage). Menghapus data browser atau berpindah perangkat dapat menghilangkan data lokal.

Apakah saya perlu login?

Tidak untuk versi lokal ini.

Apakah tanggal otomatis akurat?

Parser menggunakan tanggal dan waktu perangkat. Untuk deadline, sebaiknya tuliskan waktu jika jam benar-benar penting.

Bagaimana jika deadline tidak dikenali?

Kartu akan menampilkan peringatan bahwa deadline tidak terdeteksi. Gunakan salah satu format pada Panduan.

Apakah data bisa diakses dari HP lain?

Belum pada versi localStorage. Untuk sinkronisasi antarperangkat, aplikasi perlu backend/database.
